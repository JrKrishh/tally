Rank coding agents without paying for the whole benchmark.

Most cells in an agent benchmark are foregone conclusions, and a benchmark's own history says which. Tally runs only the uncertain ones, caps the attempts, and hands back the ranking with a receipt. Below is its planner replaying 13,915 real frontier-model trajectories, then a real evaluation it ran on NVIDIA Nemotron 3 Nano through Nebius Token Factory.

What the real run caught that the replay could not

History's "certain pass" doesn't transfer down a tier

Before the full run, eight tasks history called certain were run once anyway. Every near-certain fail failed; three of four near-certain passes failed too. The replay could never see this: all six models it learned from are frontier models. So for a model unlike its history, Tally now skips certain fails only.

The API balance ran out three hours in

117 trials came back HTTP 402. In-flight trials kept finishing for an hour afterwards, so a watchdog that waits for progress to stall never fired. It now stops on the first 402, and run --retry-errored re-ran exactly those cells the next morning in 2 h 45 m for $1.76, every earlier verdict untouched.

Can a reasoning model stand in for history?

A benchmark nobody has run has no history, so Nemotron 3 Super read each task and estimated how hard it is. It reads self-contained tasks weakly and repository tasks not at all, where issue length alone predicts better.

One idea, tested once

Can a layer lift a small model?

Nemotron Nano ended most of its trials by declaring the task done, and most of those claims were false. The fix to try without training anything is a layer around the agent: it reads answers the stock agent threw away, and it answers "done" with shell checks written from the task text, sending failures back to the agent. Every choice was made on 40 dev tasks; the other 39 were split off before any trajectory was read, then run once.

How it works

Three commands

1 · plan

Reads the benchmark's history and writes which tasks to run for the new model, how many attempts, which to skip, and a few skipped ones to run once as a check.

python -m tally.plan --lo 0.10 --hi 1.0
2 · run

Checks the key, model and disk, then has Harbor drive the Terminus-2 agent through exactly those cells, one Docker sandbox per trial, with a watchdog and resume.

python -m tally.run --plan data/plan_terminalbench.json --phase run -n 4
3 · report

Measured where it ran, history where it skipped: accuracy, rank among the models history knows, the token and dollar receipt, and whether the skipped cells behaved as predicted.

python -m tally.report --plan data/plan_terminalbench.json

Limits

  • One agent scaffold. Scaffold choice moves cost up to 33× on identical tasks, so rankings should transfer; absolute numbers will not.
  • History is six models of one tier. The validation run shows what that costs for a weaker model.
  • SWE-bench Pro here is a 54-task subset with 40 tasks shared by all six models.
  • The frontier logs used generous 10M / 30M token budgets; the Nemotron run used far tighter ones.
  • The layer experiment is one design on one small model. A model that repairs better might gain from the same checks.
